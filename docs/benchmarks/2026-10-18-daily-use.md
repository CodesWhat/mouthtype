# Local speech evaluation, 2026-10-18

A synthetic baseline on an Apple M4 Pro with 48 GiB RAM. The debug benchmark was built from `ad9743f7f9098d438a4482109c6c699b892b774c`; both runs used already-present Parakeet v3 assets and reported zero ASR download time. Each clip had one warmup and three timed runs. Full references, hypotheses, individual timings, measured noise, software versions and model fingerprint are in [the sanitized results](2026-10-18-daily-use.json).

Both long recordings retained the final checkpoint, “The last words are silver river.” The long reference repeats a paragraph, so its low error rate measures this controlled corpus, not general human accuracy. The 20 dB and 10 dB noise mixes had zero clipped samples and measured within 0.001 dB of their requested global waveform SNR.

The first run reported 15.92 seconds for model loading/internal preparation; the later run reported 0.18 seconds with system caches warm. Those preparation values are separate from the recognition timings. The long result is about 19 minutes 47 seconds of decoded file audio. Microphone capture, resampling over a live take, power/device events, cleanup and UI delivery need coordinated native acceptance.

The saved fingerprint covers the ASR model directory and excludes the separate VAD cache. No personal recordings or absolute model-cache paths are included here.
