Mouthtype for Linux.

An experimental dictation client for Arch/Omarchy.
Install from source, then try it on your own desktop.

LINUX x86_64 · HYPRLAND · PIPEWIRE · DEVELOPMENT CLIENT

Download Linux source ↓ Looking for the Mac alpha?
  1. ↳

    Start with the right setup.

    The initial target is Linux x86_64, Arch/Omarchy, Hyprland and PipeWire. This is a terminal-driven test client with no Linux GUI. Other compositors and architectures are not supported by this client.

    Use your distro’s normal signed package management for python, python-pip, curl and pipewire-audio. Optional libnotify provides recording cues. Automatic typing additionally requires wtype and a separate opt-in.

  2. ↳

    Install the client.

    The download is the corresponding GPL-3.0 source archive for the current Mac alpha. It includes the Linux client, its setup guide and license notices, with no models or personal data bundled. It is not a Linux app ZIP or a supported packaged desktop release.

    Extract it and open a terminal in the extracted source directory. Read tools/linux-desktop/README.md, then run python3 tools/linux-desktop/install.py --prefix "$HOME/.local".

    This installs ~/.local/bin/mouthtype-linux and its payload. Keep that directory on your PATH. The installer refuses to overwrite an existing installation; choose another prefix to preserve it. It does not change shortcuts, compositor settings or services.

  3. ↳

    Prepare speech explicitly.

    From the same source directory, run python3 tools/linux-desktop/setup_speech.py --destination "$HOME/.local/share/mouthtype/speech-candidate". The destination must be new.

    This downloads and verifies the pinned speech files, creates a dedicated Python environment and writes a local configuration. It does not start recording or install an autostart service. If a required helper or binary wheel is unavailable, preparation fails without changing system Python.

    The helper prints the exact foreground launch command. Start it explicitly. For a bounded test, append --lifetime-seconds 900 after serve. Use the same launcher and configuration for all subsequent commands.

  4. ↳

    Keep the first take local.

    The default delivery is recovery-only. Start and stop one short take, then inspect the saved result with list and recover ID. Nothing is typed into another app automatically. Shut down the foreground service explicitly when finished.

    The source guide covers hold and toggle shortcuts, Escape/cancel, recovery, optional saved spellings and phrases, and basic cleanup. Inspect existing Omarchy/Voxtype bindings before choosing unused keys. Nothing replaces your bindings automatically.

    Automatic typing is a separate explicit opt-in for a native editor, with field and focus limits. Multiline/control-bearing results are refused and stay recoverable; the client does not send Return or Tab to make them fit. Mac AI cleanup and file transcription are not Linux parity promises.

Built. Still being tested.

Automated Ubuntu/Arch, synthetic audio, headless Wayland and local package checks pass for their tested components.

Physical microphone, Hyprland and Omarchy acceptance remains unverified. The Arch test-package builder in the source requires a clean committed Git checkout. The downloadable source archive has no Git history; use the source installer above.

Record your actual distro, compositor and audio versions when testing. Inspect a result before retrying an uncertain insertion. Share only the text or recordings you choose.
