EARLY DAYS. ANOTHER DESKTOP.

Mouthtype for Linux.

An experimental dictation client for Arch/Omarchy, with a bar menu, floating pill and paste delivery.
Install from source, or point your coding agent at the step-by-step install file.

LINUX x86_64 · ARCH/OMARCHY · HYPRLAND · PIPEWIRE · DEVELOPMENT CLIENT

Download Linux source ↓ Looking for the Mac app?
  1. ↳

    Start with the right setup.

    The target is Linux x86_64, Arch/Omarchy, Hyprland and PipeWire. The client is a terminal-driven service; the Omarchy plugin gives it a bar menu, a floating pill and settings. Other compositors and architectures are not supported by this client.

    Use your distro’s signed package management for python, python-pip, curl, pipewire-audio, ffmpeg, wl-clipboard, wtype and libnotify. Optional Fast and Thorough cleanup download a checked upstream llama-server, so nothing is compiled and no toolchain is needed (only the opt-in --build-server path wants git, cmake and base-devel). Keep ~/.local/bin on your PATH.

  2. ↳

    Install the client.

    The download is the GPL-3.0 source archive for the current Mac release. It includes the Linux client, the Omarchy plugin under tools/omarchy-plugin (in archives that contain that directory), the setup guides and license notices, with no models or personal data bundled. It is not a packaged desktop release.

    Extract it and open a terminal in the extracted source directory. Read tools/linux-desktop/README.md, then run python3 tools/linux-desktop/install.py --prefix "$HOME/.local".

    This installs ~/.local/bin/mouthtype-linux and its payload. The installer refuses to overwrite an existing installation; move an old one aside to upgrade. Check it with mouthtype-linux capabilities.

  3. ↳

    Run setup.

    From the same source directory, run python3 tools/linux-desktop/setup.py. It checks the helpers first, then downloads and verifies the pinned speech model (about 465 MiB), creates a dedicated Python environment, writes a local configuration, installs the Omarchy plugin with its login service and binds Super+Alt+M (dictate) and Super+Shift+T (Transform Selection). It shows progress as it goes. setup_speech.py does the speech step alone if you want it by itself.

    Confirm it with mouthtype-linux doctor, which reports what is missing and how to fix it.

  4. ↳

    The Omarchy plugin.

    Setup installs the plugin for you. It adds the Mouthtype widget to the right side of the bar, enables a systemd user service so dictation starts with every login and is restarted if it stops, and restarts the Omarchy shell. To install it by hand, run python3 tools/omarchy-plugin/install.py; pass --no-autostart to keep the service manual. Launch at Login in the menu toggles it later.

    From the menu: start, stop and cancel dictation, read and copy recent takes, retry saved audio, transcribe one audio file, choose a microphone and test its level, choose the Classic or Hi-Fi floating pill and the text font, and pick Basic, Fast or Thorough cleanup. Desktop notifications are errors-only by default, because the pill already shows recording and transcribing.

    Fast and Thorough download verified local models on your explicit request, and you can cancel a download while it runs. Fast and Thorough also download a pinned, checksum-verified upstream llama-server (about 17 MB). Nothing is compiled unless you pass --build-server.

  5. ↳

    Log in again, then speak.

    Log in again so the first-run step finishes anything left over and the widget and keys are live. Press Super+Alt+M, speak, and press it again. Basic cleanup is on by default, so the text comes back tidied.

    The default delivery is recovery-only: a take is saved locally and nothing is typed, and the take lands under Recent takes on Home. The first time you open the bar menu, a card asks where your words should go: paste where you are typing (recommended) or just save them. You can change it later in Paste Options, where you choose Paste into the active window to paste each take into the window that was active when you started, with your previous text clipboard restored. Terminals get Ctrl+Shift+V and no multi-line pastes.

    Under Change Dictation Shortcut…, pick press-to-toggle or hold-to-talk on any key, including a lone modifier such as Right Ctrl. Keys Hyprland already binds are refused. Watch the pill at the bottom of the display. Every take also stays readable with list and recover ID.

    Before you remove a package, run mouthtype-linux-setup --uninstall to take out the bar widget, the shortcuts and the login service link.

    Linux cannot detect password fields, so pasting goes wherever the cursor is, and insertion is not verified. Audio and text never leave the machine.

Packages are coming.

An Arch (AUR) recipe and a signed apt repository for Debian 13 and Ubuntu 24.04 or newer are built and tested, but neither is published yet. yay -S and apt install do not work today, so install from source. Package installs will set themselves up at your next login.

Built. Tested on one desk.

Automated Ubuntu/Arch, synthetic audio and headless Wayland checks pass, and the full flow (microphone takes, pill, paste delivery, file import and local cleanup) was exercised on one Arch/Omarchy desktop with Hyprland 0.56 and PipeWire.

Wider hardware, HiDPI and multi-monitor acceptance remains open. The Arch test-package builder in the source requires a clean committed Git checkout; the downloadable archive has no Git history, so use the installers above.

Coding agents: agent-install.md is the same procedure as an ordered checklist with a check after every step.
