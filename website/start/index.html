A SMALL START

Your first words.

A key, a thought, and somewhere to put it.
Here’s how to get Mouthtype ready on your Mac.

ALPHA · macOS 26+ · APPLE SILICON

Download for Mac ↓ Source code (GPL-3.0) ↗ Linux test client
  1. ↳

    Make yourself at home.

    Download the Mouthtype ZIP using the button above, expand it, then drag Mouthtype.app into Applications. Quit an older copy before replacing it, and open the app from Applications.

    This is 0.1.0-alpha.8 (build 8), for Apple Silicon Macs running macOS 26 or later. This is an early test build; read the notes below before your first dictation.

  2. ↳

    Let it hear. Let it type.

    Allow Microphone access to record your voice and Accessibility access to insert text into the app you’re using. Set Up Mouthtype focuses on one card at a time and advances when each prerequisite is ready. You can defer it and reopen it from Settings → General.

  3. ↳

    Give it a moment.

    The speech model downloads on first launch. Wait until it’s ready before your first take. Downloads need internet access; speech recognition and cleanup then run on your Mac.

    Basic cleanup works without a separate cleanup model. Fast and Thorough are optional downloads. You can explore those later.

  4. ↳

    Say your thing.

    Click a blank TextEdit document. Hold Fn, say a short sentence, then release. Wait for your words to appear. The shortcut can be changed if Fn isn’t your thing.

    Try a second sentence without clicking or typing between takes. Each take should appear once, with a space between them. Read the result before sending it anywhere.

Hold. Speak. Release.

Mouthtype finishes the take, cleans up the text and inserts it where you started.

If something gets stuck ↘

A little help, if you need it.

Read the documentation for shortcuts, cleanup, saved words and recovery.

No text?

Check Microphone and Accessibility access, wait for the model to be ready, and confirm that a text field is selected. If a warning appears, check whether the text already appeared before trying again.

Keep the words.

If delivery fails, use the recovery card’s Copy action. Saved Recordings keeps retained audio available. Check the destination first so a second paste doesn’t duplicate a take.

Something sounds wrong?

Names and recognition can still be wrong. Include your Mouthtype version, macOS version, destination app, what you said and what appeared when reporting a problem. Share only the text or audio you choose.

What’s in this alpha?

This alpha includes Transcribe Audio File…: choose one WAV, AIFF or M4A, then review and explicitly Copy or Save Text. It preserves your original, with no automatic paste. See the file transcription guide.

Alpha.8 adds Saved audio in Settings → General: choose a completed-recording age and size limit for the next launch. Text and recovery recordings stay. Microphone setup now follows actual recording readiness. See saved audio.

Settings includes a remembered microphone choice, optional Quiet other audio and Live words. Both quieting and provisional words are off by default. The finished take still inserts once. Settings groups controls into General, Writing, Appearance and Diagnostics.

Coming from alpha.1–3? Download the current Mac alpha once and replace the app manually to get the built-in updater. After that, use Check for Updates… in the menu or Settings → General. Linux source testing is experimental; there is no packaged Linux desktop release.
